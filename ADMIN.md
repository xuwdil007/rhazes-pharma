# Админ-панель РАЗЕС ФАРМА

## Запуск

```bash
npm run build
npm start
```

Сайт: `http://localhost:4173`

Админка: `http://localhost:4173/#/admin`

## Первый вход

- Логин: `admin`
- Пароль: `Rhazes2026!`

Перед публикацией создайте файл `.env` по образцу `.env.example` и обязательно
замените `ADMIN_PASSWORD` и `ADMIN_SECRET`.

## Редактирование

1. Войдите в админку.
2. Выберите страницу или общий раздел в левом меню.
3. Выберите целый блок страницы, например Hero, статистику или продукцию.
4. Измените нужные поля и нажмите «Сохранить весь блок».
5. В поле «Дополнительный текст» можно добавить новую информацию в блок.
6. Блок можно целиком скрыть и затем снова восстановить.

Изменения сохраняются в `backend/data/content.json` и применяются для всех посетителей.
Кнопка «Экспорт» создаёт резервную JSON-копию, а «Сбросить» возвращает исходные
тексты из React-кода.
